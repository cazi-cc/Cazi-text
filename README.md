# 希尔伯特立方

一个被三维希尔伯特曲线填满的立方体，可以旋转、缩放、切换阶数和配色的展示页。
单个 HTML 文件，不依赖任何库，用 WebGL2 实时渲染。

## 打开

用浏览器直接打开 `index.html` 即可（需要支持 WebGL2：新版 Chrome、Edge、Firefox、Safari）。
也可以放到任意静态服务器或 GitHub Pages 上。页面会尝试加载 Google Fonts 的三款字体，加载不到时自动使用系统字体。

## 可以做什么

- **阶数 1–6**：从 8 个顶点到 262,144 个顶点。切换阶数时，曲线沿着自身逐段展开或折叠，而不是直接替换。触屏设备上限为 5 阶。
- **生长动画**：底部色带是拉直后的曲线，拖动它或按播放键，可以看曲线从起点一路画到终点；左上角实时显示当前位置 *d*、它的八进制地址和格点坐标。
- **两种渲染**：实体（带光照、遮蔽和镜面倒影的发光管道）与透视（叠加发光的细丝，可以看穿整个立方体）。
- **两种视角**：环绕，以及钻进晶格内部沿曲线飞行的穿梭视角。
- **分解**：按递归层级把八个子立方体逐层推开，看清曲线的自相似结构。
- **六套配色**，以及流光、断层扫描、色彩流动、星尘、玻璃外框、倒影等效果开关。
- **自动演示**：自动轮播以上各种状态。

## 操作

| 操作 | 作用 |
| --- | --- |
| 拖动 | 旋转（穿梭视角下为环顾） |
| 滚轮 / 双指捏合 | 缩放（穿梭视角下为调速） |
| 双击 | 复位视角 |
| `1`–`6` | 阶数 |
| `空格` | 播放 / 暂停生长动画 |
| `X` / `V` | 透视渲染 / 穿梭视角 |
| `C` / `E` | 下一套配色 / 分解 |
| `D` / `R` / `F` / `H` | 自动演示 / 复位 / 全屏 / 隐藏界面 |

## 实现要点

- **曲线**：用 Skilling 的 transpose-to-axes 算法由序号直接算出格点坐标。相邻两阶是嵌套的（*n*+1 阶的第 *i* 个顶点落在 *n* 阶第 ⌊*i*/8⌋ 个顶点的格子里），展开动画和分解视图都建立在这一点上。
- **管道**：每条线段是一个实例化的包围盒，端点坐标存在一张整数纹理里，由顶点着色器按实例序号读取；片元着色器对胶囊体做精确的光线求交并写入深度，所以任何距离下管道都是圆的，26 万条线段也只需要一次绘制调用。
- **画面**：场景渲染到 HDR 缓冲，经多级降采样辉光、ACES 色调映射、暗角、色散和抖动后输出；分辨率会根据帧时间自动升降。

在浏览器控制台里可以通过 `hilbertCube` 读写当前状态，例如 `hilbertCube.apply('order', 5)`。
